# UAG app-wide convergence audit — 14 September 2026

## Scope and evidence

Source audit of every `*screen.dart` in `lib`, named-route dispatch in `lib/main.dart`, route aliases, nested screens, both app-entry gates, feature-lock states, navigation catalog, drawer and shared typography/layout. This is an engineering source inventory, **not a claim that every route has been exercised against production**. Live feature flags, entitlements, role checks, authentication and Firebase availability still determine what a user can open. Production status below means registration/reachability in current source, not launch certification.

Initial state is recorded by the integration worker in `docs/audits/overnight_start*`. Existing dirty implementation is preserved. Initially this worker edited only this report; after the authorised continuation it also owns the previously clean Help Centre screen. Changes attributed to shared typography are owned by the integration worker; community implementation and ad policy have dedicated reports.

### Reading the table

- Routes are exact constants where declared. `nested/constructor` means no named route is declared in that file. A declared constant alone does not prove it is registered.
- Visual system describes the source composition; Material widgets inside an ARC theme are not inherently visual contamination. `No confirmed` means no demonstrated contamination, not a full visual certification.
- Phone and desktop issue columns deliberately use `Unverified` unless a specific source risk is identified. No runtime overflow, contrast or accessibility clearance is implied. Responsive helpers alone do not prove correctness.
- Font column separates direct legacy declarations from shared exposure. Initially `AppTheme.heroFontFamily = VT323`, inherited by `ArcUiTokens.pageTitle`/section titles and `ArcRaidersTheme.hubTitle`. Integration replaces the shared family with existing SpaceGrotesk and updates metrics; four direct scanner declarations and two user-details declarations are replaced too. The font asset stays available for wider UAG.
- Ads are source slots, not filled impressions. `Yes slot` includes an explicit banner or enabled/default shell slot; delivery remains conditional on tier, consent, SDK/platform and inventory. `No local slot` does not certify an ancestor never displays an ad. The dedicated monetisation matrix is authoritative for treatment and final policy.
- `Shared typography` in the last column means presentation changes inherited from the shared fix; it does not mean each screen file was edited. Community rows are owned separately and their detailed redesign report records final changes.
